# MakeOrbit GearGenerator 1.0.0

First public release of the 645DF gear generator for Autodesk Fusion.

## Included

- External involute gears, internal ring gears, and roller-chain sprockets
- Mandatory tooth count with automatic dimension derivation
- Optional bore, dimension cross-checking, and rounded tooth-tip/root geometry
- Extruded Fusion component output
- STEP, STL, 3MF, and DXF export
- Direct authenticated local transfer to 645DF MakeOrbit 2.9.9
- German UI when Fusion is German; English for all other languages
- Illustrated parameter tooltips
- macOS and Windows installers
- Bilingual German/English PDF guide
- Platform-specific MakeOrbit availability guidance for macOS and Windows
